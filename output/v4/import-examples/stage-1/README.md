# V4 Stage 1 simulated CSV data

`schools`, `users`, `roles`, `assignments`, `school_definitions`, `record_links`, and `change_logs`.

They follow the Stage 1 subset of `../../planning/schema-contract.csv`. They are seed/import examples for review, not a production export and not an upload endpoint. Passwords and password hashes are excluded.
