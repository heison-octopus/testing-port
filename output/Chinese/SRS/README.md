# BHSS 學生成長歷程平台 — SRS 索引

## 文件用途

本目錄載有 BHSS 學生成長歷程平台的模組化軟件需求規格（SRS）。文件把現有架構整理成可驗收的要求；尚待校方決定的事項，不會當作已落實政策。

英文版位於 [`../../English/SRS/`](../../English/SRS/)。中英文版本採用相同的需求編號、限制、狀態及決策編號，但中文內容按香港學校日常用語重新編寫，並非逐句翻譯。

## 資料依據次序

1. 校方原始文件只作依據，不會在本項目內暗中改寫。
2. [`../核心資料關係.md`](../核心資料關係.md) 是現時的架構基準。
3. [`../角色及權限.md`](../角色及權限.md) 界定存取模式。
4. [`../討論問題.md`](../討論問題.md) 統一記錄未決事項。
5. [`../最新發現及問題 v2.md`](../最新發現及問題%20v2.md) 按確定程度分開保存最新會議內容。
6. `mock/` 只屬示範；如與上述文件不一致，以上述文件為準。

## 要求狀態

| 標示 | 意思 |
|---|---|
| 原始要求 | 有校方原始資料直接支持 |
| 已確認工作決定 | 現階段架構採用，仍待正式簽認 |
| 建議架構 | 已提出具體做法，待校方確認 |
| 政策待定 | 需由指定決策人作業務決定 |
| 臨時技術上限 | 政策未定前用來避免無限制輸入的可設定上限 |

## 未決政策的處理

若校方政策尚未確認，文件會同時列出「政策待定」及另行標示的「臨時技術上限」。臨時上限只為保障系統，不代表已替校方作出政策決定。
