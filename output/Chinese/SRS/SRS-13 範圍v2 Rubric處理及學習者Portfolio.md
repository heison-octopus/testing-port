# SRS-13 範圍 v2：Rubric、媒體處理及學習者 Portfolio

## 1. 狀態及依據

本模組記錄 2026 年 10 月 26 日 kickstart 會議後已批准用於 POC 的架構解讀，並以 [`../最新發現及問題 v2.md`](../最新發現及問題%20v2.md) 的四類清單為依據。正式 RC360 內容及正式人臉處理政策仍屬外部依賴，不能視為已確認要求。

## 2. 核心輸入及出席

| ID | 要求 | 狀態 |
| --- | --- | --- |
| V2-FR-001 | 平台須提供一套清晰的活動輸入規格；現階段不接受每校任意更改資料結構。 | 已批准 POC 解讀 V2-A01 |
| V2-FR-002 | 學校負責先整理來源資料；平台負責驗證必填欄位、預覽身份配對及保存批核／審計紀錄。 | 已批准 POC 解讀 |
| V2-FR-003 | 活動須支援公開簡介（最多 20,000 字元）、內部背景（最多 20,000 字元）、開始／結束時間、學生上載時段、封面顯示方式、原定名單、媒體狀態及批核狀態。 | 已批准 POC 解讀 |
| V2-FR-004 | 活動老師須為每名原定參加者記錄 `attended`、`late`、`partial` 或 `absent`。 | 已批准 POC 解讀 |
| V2-FR-005 | 原定參加者如被標示為 `absent`，紀錄進入 `pending_approval`，由職員或 SchoolAdmin 批核或退回。 | 已批准 POC 解讀 |
| V2-FR-006 | 平台不可暗示已設有缺席解釋表。 | 會議範圍 V2-A03 |

## 3. 標籤及 Rubric 能力

| ID | 要求 | 狀態 |
| --- | --- | --- |
| V2-FR-010 | 標籤目錄須列明 `catalogue_kind`、版本、狀態及 `assessment_capable`。 | 已批准 POC 解讀 |
| V2-FR-011 | VASK 及活動類型只作描述，不可顯示分數或階段輸入。 | 已批准 POC 解讀 V2-B02 |
| V2-FR-012 | 可評估 Rubric 須定義範疇、最低／最高階段、佐證規則、版本及發布權責。 | 已批准 POC 解讀 |
| V2-FR-013 | 活動選取 Rubric 範疇時，只建立預期觀察標籤，不會建立評估紀錄。 | 已批准 POC 解讀 V2-B01 |
| V2-FR-014 | POC 先完成一條 Skills Builder 1–16 流程，才開啟 RC360 平行結果。除非另有獲批轉換規則，兩套 Rubric 不會互相平均。 | 已批准 POC 解讀 V2-B03 |

## 4. 活動表格對象

| ID | 要求 | 狀態 |
| --- | --- | --- |
| V2-FR-020 | 同一份活動表格可包含依次排列的老師、學生及同儕問題區塊。 | 會議確認 V2-A09 |
| V2-FR-021 | 每個區塊須保存版本、對象、狀態及題目次序。 | 已批准 POC 解讀 |
| V2-FR-022 | 草稿區塊不可在學生或同儕任務出現；發布後才可向指定對象顯示。 | 已批准 POC 解讀 V2-B10 |
| V2-FR-023 | 同儕互評須明確分配評核人及被評學生，即使區塊屬同一份表格亦一樣。 | 既有核心規則 |

## 5. 可監察媒體處理

| ID | 要求 | 狀態 |
| --- | --- | --- |
| V2-FR-030 | 每項相片／錄音上載須建立或連結處理工作，並保存類型、供應商、狀態、進度 0–100、重試 0–3 次、輸入清單、輸出／錯誤、執行人及時間。 | 已批准 POC 解讀 |
| V2-FR-031 | 工作狀態須支援 `queued`、`processing`、`retry_wait`、`needs_review`、`completed`、`failed_terminal` 及 `cancelled`。 | 建議架構 |
| V2-FR-032 | 人臉處理可輸出零個或多個候選，包括學生 ID、信心值 0–100 及決定狀態。 | 已批准 POC 解讀 |
| V2-FR-033 | 人手確認、拒絕、標示不明或非學生後，候選人臉才可連結至學生佐證。 | 已批准 POC 解讀 |
| V2-FR-034 | 語音處理須保存原文、整理後文字、語言、時間、偵測講者、確認身份及語氣助詞刪減紀錄。 | 已批准 POC 解讀 |
| V2-FR-035 | Rubric 建議須保存佐證片段、Rubric／版本、範疇、有效範圍內的建議階段、Prompt 版本、模型／處理器、信心值 0–100、理由及人工決定。 | 已批准 POC 解讀 |
| V2-FR-036 | 校方提供的測試相片須與正式資料分隔，亦不可當作正式私隱合規證明。 | 待確認 V2-D03 |
