# V4 Stage 1 CSV examples

Seven relational foundation tables, freshly generated from synthetic fixtures. See `manifest.json` for counts and the implemented column convention. Passwords and password hashes are excluded. Subject and department definitions plus a validated relation example are included.

These files are review/seed-contract examples. Stage 1 does not provide CSV upload/commit; that workflow is staged separately. Existing flat examples are legacy contracts and must not be mixed into the V4 schema blindly. Pre-stage backups and hashes are in `../../import-examples-v2/stage-1/`.
